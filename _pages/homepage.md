# Academic Pages

This is a minimalist theme for creating a personal academic website on GitHub Pages. It has a single left sidebar menu and a clean design. The design is based on the Minimal Mistakes Jekyll theme.

## Usage

To use this theme, you can fork this repository or use it as a template.

1. Fork the repository

2. Edit the `_config.yml` file to customize your website

3. Edit the `about.md` file to add your own information

4. Add your content
